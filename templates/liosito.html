LIOSITO

Sistema de gestión de proyectos impulsado por IA y oráculo técnico.

Sobre el Proyecto

LIOSITO es un avanzado sistema de gestión de proyectos con arquitectura RAG. Actúa como un oráculo técnico donde se pueden integrar repositorios de GitHub para aumentar su conocimiento. Asigna tareas de manera inteligente a los integrantes del LIA según sus capacidades, estableciendo pesos por tarea y manteniendo un ranking de productividad para motivar el trabajo en equipo.

Objetivo de Impacto

Optimizar el flujo de trabajo del laboratorio, motivar la participación activa mediante la gamificación (ranking) y servir como una memoria técnica centralizada del LIA para evitar la pérdida de conocimiento entre generaciones.

Stack Tecnológico

  • • Arquitectura RAG e Inteligencia Artificial
  • • Python y Framework Web (Flask)
  • • GitHub API para lectura de repositorios
  • • Base de Datos relacional para el ranking

El futuro del proyecto

  • • Análisis de código automático y sugerencias de mejora
  • • Integración directa con entornos de desarrollo (IDEs)
  • • Recordatorios automatizados de tareas
